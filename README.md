# Saudi Arabia Refinery & Energy Data Visualization

This project provides interactive dashboards and visualizations for Saudi Arabia's refinery locations, production, demand, and energy reserves.

## Main Files

- `refinery-map.html` — Interactive map of Saudi refineries
- `production-demand-chart.html` — Chart comparing refined product production and demand
- `saudi.html` — Combined dashboard for Saudi energy data


## Data Files (in `data/`)

- `Refinery capacities csv.csv` — Refinery capacities
- `Production of Refined Products csv.csv` — Production data
- `refined products demand csv.csv` — Demand data
- `Exports of Refined Products 2024 csv.csv` — Export data
- `Reserves, Natural Gas csv.csv` — Natural gas reserves
